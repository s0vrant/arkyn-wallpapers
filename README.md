# Arkyn OS wallpapers

Full-size wallpapers from the Arkyn OS identity, for download. They ship with Arkyn OS 3.0.0, and the
gallery is at [arkyn.datsov.com/wallpapers](https://arkyn.datsov.com/wallpapers/).

The images are **assets on the [v3.0.0 release](https://github.com/s0vrant/arkyn-wallpapers/releases/tag/v3.0.0)**,
not files in this repository. Each one comes in five sizes:

| Size | Pixels |
|---|---|
| 4K | 3840 × 2160 |
| QHD | 2560 × 1440 |
| Full HD | 1920 × 1080 |
| Ultrawide | 5120 × 2160 |
| Ultrawide | 3440 × 1440 |

Wallpapers: Monolith (dawn, day, dusk, night: on Arkyn they follow the time of day), Monolith Stealth,
Aperture and Strata.

## Check a download

`SHA256SUMS` is attached to the release and copied in this repository. In the folder with your downloads:

```
sha256sum --ignore-missing -c SHA256SUMS
```
